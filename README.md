buygrim.lua
Navigates to "Incarnation of Cazic" and buys N x
"Grimoire of Profound Experience" from the point-merchant window, paying in "Ancient Fragments of Knowledge".

    Usage:  /lua run buygrim        -- buy as many as currency allows
            /lua run buygrim max    -- same as above, explicit
            /lua run buygrim 5      -- buy at most 5


buytokens.lua
Navigates to "Walter" and buys "Token of Legendary Might",
which costs 60 x "Token of Might" each.

Usage:  /lua run buytokens        -- buy as many as you can afford
		/lua run buytokens max    -- same, explicit
		/lua run buytokens 3      -- buy at most 3 (needs 180 tokens)
